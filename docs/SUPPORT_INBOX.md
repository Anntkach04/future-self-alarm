# Фільтр листів Future Self Alarm

Усі листи з апки йдуть на **dyniza@uxdyniza.com**  
у темі завжди є мітка: **`[Future Self Alarm]`**

Нижче — як зробити, щоб вони лягали в окрему папку/label і не губились серед інших.

---

## Gmail / Google Workspace (найімовірніше для uxdyniza.com)

1. Відкрий https://mail.google.com під акаунтом `dyniza@uxdyniza.com`
2. Шестерня (Settings) → **See all settings**
3. Вкладка **Filters and Blocked Addresses**
4. **Create a new filter**
5. У полі **Subject** впиши:
   ```
   [Future Self Alarm]
   ```
6. Натисни **Create filter**
7. Постав галочки:
   - ✅ **Apply the label** → створи label `Future Self Alarm` (або обери існуючий)
   - ✅ (опційно) **Skip the Inbox (Archive it)** — тоді листи одразу тільки в label, не в Primary
   - ✅ (опційно) **Star it** — щоб помітніше
8. **Create filter**

Готово. Нові support-листи будуть збиратись під label **Future Self Alarm**.

### Перевірка
Попроси когось (або себе) надіслати лист з темою  
`[Future Self Alarm] Support`  
на `dyniza@uxdyniza.com` — має з’явитись у цьому label.

---

## Apple Mail (якщо читаєш на Mac / iPhone)

1. **Mail → Settings → Rules** (на Mac)
2. **Add Rule**
3. Назва: `Future Self Alarm`
4. Якщо **Subject** містить `[Future Self Alarm]`
5. Тоді: **Move Message** → папка `Future Self Alarm` (створи папку спочатку)
6. OK → Apply

На iPhone правила з Mac синхронізуються, якщо той самий акаунт через iCloud/Exchange налаштований з правилами на сервері; для Gmail надійніше ставити фільтр саме в Gmail (кроки вище).

---

## Outlook (outlook.com / Microsoft 365)

1. Outlook → шестерня → **Mail → Rules**
2. **Add new rule**
3. Умова: **Subject includes** → `[Future Self Alarm]`
4. Дія: **Move to** → папка `Future Self Alarm`
5. Save
